# aura_clap — scoping

CLAP is the first plugin protocol Aura hosts: open, a clean main-thread / audio-thread split, and a usable Rust host library (`clack-host`, on crates.io since 0.2). A crate of its own keeps protocol code out of the neutral host seam. See [`../../../scoping/plugin-hosting.md`](../../../scoping/plugin-hosting.md).
